## Empresa

A Locrider Distribuidora é uma pequena empresa que trabalha com venda e distribuição de materiais de escritório e suprimentos para empresas.

A empresa possui os setores de Administração, Financeiro, Comercial e Atendimento. A rede local foi criada para conectar os computadores, impressoras e o servidor utilizado pela empresa.

A rede funciona apenas para comunicação interna e não possui acesso a Internet.

## Sobre o projeto

O projeto foi feito no Cisco Packet Tracer utilizando uma rede LAN cabeada.

Os computadores, impressoras e servidor são conectados através de um switch central, permitindo a comunicação entre os dispositivos dos diferentes setores da empresa.

Os dispositivos possuem endereços IPv4 configurados manualmente e os testes de ping foram utilizados para verificar a comunicação da rede.

## Como abrir o projeto

1. Ter o Cisco Packet Tracer instalado no computador.
2. Baixar o arquivo `projeto-lan.pkt`.
3. Abrir o Cisco Packet Tracer.
4. Abrir o arquivo `projeto-lan.pkt`.
5. Aguardar o projeto carregar para visualizar e testar a rede.
